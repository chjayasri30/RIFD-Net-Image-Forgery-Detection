# RIFD-NET: A Robust Image Forgery Detection Network

## About the Project

RIFD-NET is a deep learning-based image forgery detection project developed to identify manipulated images using a Convolutional Neural Network (CNN). The project explores automatic feature extraction to distinguish authentic images from forged images.

The project focuses on image manipulation detection and aims to improve robustness against common image transformations such as compression, resizing, and noise.

## Objectives

- Detect forged and authentic images.
- Explore CNN-based feature extraction for image forgery detection.
- Study image manipulation techniques such as copy-move forgery and image splicing.
- Explore the effects of image transformations on forgery detection.

## Technologies Used

- **Programming Language:** Python
- **Deep Learning:** Convolutional Neural Network (CNN)
- **Development Tools:** Jupyter Notebook
- **Libraries:** Refer to `requirements.txt` for the project dependencies.

## Setup and Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/chjayasri30/RIFD-Net-Image-Forgery-Detection.git
   ```

2. Navigate to the project directory:

   ```bash
   cd RIFD-Net-Image-Forgery-Detection
   ```

3. Create and activate a Python virtual environment.

4. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Open the Jupyter Notebook or run the appropriate Python script according to the project workflow.

**Note:** The exact execution steps may depend on the dataset, trained model files, and configuration used by the project.
